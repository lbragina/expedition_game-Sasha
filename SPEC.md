# «Экспедиция» (L'Expédition) — Архитектура обучающей игры

## 1. Концепция и принципы
«Экспедиция» — это офлайн PWA-игра (веб-приложение для установки на экран «Домой» iPhone в вертикальной ориентации).
* **Игрок:** Саша, 12 лет, учится во французской школе (класс 6e), любит математику, играет в Minecraft, скейт-игры и Fortnite.
* **Длительность сессии:** 10–15 минут в день (6–7 заданий вперемешку).
* **Стартовый уровень:** на год ниже возраста (CM2), далее сложность адаптируется сама (от CM2 до 5e).

### Вдохновение (только механики и ощущения, без чужих персонажей и названий):
* **Из Minecraft:** добыча ресурсов за ответы (дерево, камень, железо, золото, алмазы) и строительство своей 2D-базы в собственном блочном пиксельном стиле.
* **Из скейт-игр:** комбо-множитель за серию верных ответов (`×2`, `×3`… до `×5`) с названиями трюков (*Ollie !*, *Kickflip !*, *Heelflip !*, *360 Flip !*) и анимацией скейта.
* **Из Fortnite:** сезонный пропуск на 4–6 недель (30 тиров), еженедельные челленджи, скины аватара и раскраски деки скейта.

### Железные правила:
1. **Игра заканчивается:** 1 основная экспедиция в день и 1 бонусная. Никакой бесконечной ленты.
2. **Нет таймеров на ответ:** никаких обратных отсчётов во время решения задачи, чтобы не провоцировать угадывание наугад.
3. **Ошибка — не наказание:** после ошибки даётся короткое объяснение и шанс решить похожую задачу по ступенькам.
4. **Награда за рассуждение:** повторный тык наугад не даёт очков.
5. **Безопасность и приватность:** без рекламы, встроенных покупок, чатов, аккаунтов и аналитики. Все данные хранятся только на телефоне.

## 2. Ежедневный игровой цикл
1. Выбор следующей доступной страны на карте мира.
2. Прохождение 6–7 заданий в порядке: **2 Математика → 1 Логика → 1 IQ → 1 Критическое мышление → 1 Кругозор → 1 Финальный «босс»**.
3. **Метакогнитивная проверка (иногда, ~20% задач):** перед подтверждением ответа появляется плашка *«Tu es sûr à combien ?»* («Насколько ты уверен?» — 100% / 50% / Угадываю). Это тренирует самооценку и рефлексию.
4. **Встроенный черновик (Scratchpad):** на экране задачи доступна выдвижная полупрозрачная пиксельная доска в клетку для рисования пальцем и расчётов в столбик.
5. Открытие страны на карте вместе с **записью в «Дневнике капитана»** (короткий нарратив от первого лица, связывающий страну, скейт, стройку и исторический/географический факт).
6. Трата ресурсов на стройку базы и продвижение по сезонному пропуску.

## 3. Игровые механики и экономика

| Механика | Как работает |
| :--- | :--- |
| **XP и уровни** | Верный ответ = `10 XP × сложность × комбо`. Уровни со званиями (*Débutant → Éclaireur → Stratège → Maître de la logique…*). Первые 3–4 уровня берутся за первую неделю. |
| **Комбо (скейт)** | Серия верных ответов поднимает множитель до `×5`. При каждом повышении — 8-bit звук и анимация трюка. Ошибка сбрасывает множитель до `×1`, но не сгорают набранные очки. |
| **Ресурсы** | Сложность 1–3 → Дерево (Bois), 4–5 → Камень (Pierre), 6–7 → Железо (Fer), 8–9 → Золото (Or), 10 → Алмаз (Diamant). |
| **База (12×12)** | Сетка-остров (вид сверху с псевдо-объёмом в пиксель-арте, с поддержкой зума для пальцев). Постройки: Дом, Башня, Рампа для скейта (аватар периодически делает на ней трюки), Обсерватория (раз в день даёт мини-вопрос по астрономии за алмаз), Зал славы. |
| **Мастерская («???»)** | С первого дня на базе стоит запертая постройка с замком. Открывается поэтапно: 1) Пиксельный редактор скинов 16×16 (после окончания разогрева); 2) Дизайн деки скейта (уровень 10); 3) Свой блок для базы (за первую задачу `★★★`); 4) Редактор своих задач для мамы (во 2-м сезоне). |
| **Карта мира** | Каждая экспедиция открывает страну. На открытых странах и на базе иногда прячутся сундуки с компасами (нужно найти визуально). |
| **Сезонный пропуск** | 4–6 недель, 30 тиров. Темы сезонов (*Древний Египет*, *Космос* и др.). Случайные сундуки в конце дня дают только косметику, не влияя на баланс. |
| **Серия дней (Streak)** | Счётчик дней подряд с автоматической «заморозкой» на 1 день в неделю. |
| **Подсказки-компасы** | Трёхуровневая подсказка: 1 компас = Намёк (*Indice*), 2-й = Метод (*Méthode*), 3-й = Первый шаг (*Premier pas*). Готового ответа нет никогда. Бесплатная опция: *«Demander au mentor»* (обсудить с мамой, подтверждается родительским PIN-кодом). Компасы даются за `×5` комбо, 3 дня подряд, челленджи и найденные сундуки. |
| **Звёздные задачи** | Видны сразу по золотой рамке: `★` (сложность 5–6, `×3 XP`), `★★` (7–8, `×5 XP` + редкий блок), `★★★` (9–10, `×10 XP` + уникальная косметика + кубок в «Зал славы»). **Бонус за смелость:** попытка решить звёздную задачу даже при ошибке даёт утешительные XP и **не сбрасывает комбо**. |

## 4. Педагогический движок

### Мягкий старт (первые 2 недели)
1. **Дни 1–7 («Разогрев»):** 6 лёгких задач (сложность 1–3, уровень CM2) + 1 необязательная задача-«сундук» (сложность 5–6, ошибка не сбрасывает комбо). Цель: ~90% успеха.
2. **Дни 8–14 («Набор скорости»):** 4 лёгкие, 2 средние (сложность 4–5, уровень 6e) + «сундук». Цель: ~85% успеха.
3. **Переход в адаптивный режим:** происходит автоматически, когда выполнены **оба** условия: пройдено ≥ 10 экспедиций И средний процент верных ответов ≥ 85%. Подаётся как открытие нового континента.
4. **Страховка:** если 2 дня подряд результат < 60%, сложность временно снижается.

### Адаптивность (упрощённый Elo) и «Белые пятна»
* У каждой из 5 категорий свой скрытый рейтинг игрока. Игра подбирает задачи так, чтобы держать процент успеха в коридоре **70–80%**.
* **Белые пятна и лесенки:** ошибка в задаче сложности `4+` ставит на карте «белое пятно» (туман). В следующей экспедиции появляются 1–2 подводящие задачи попроще из массива `ladder` этой задачи. После их решения возвращается исходная задача (или её изоморфный вариант). Одновременно активно не более 3 пятен.

## 5. Категории и типы задач

### Темы (французская школьная программа CM2–5e):
* **Математика (`math`):** устный счёт, дроби (`fractions`), проценты, делимость (`divisibilité`, `PGCD`, `PPCM`), геометрия на клетках (`périmètre`, `aire`), задачи в стиле конкурса *Kangourou*.
* **Логика (`logic`):** рыцари и лжецы, табличные задачи, взвешивания, переправы, мини-судоку.
* **IQ (`iq`):** числовые и визуальные последовательности, матрицы Равена (рендерятся через SVG), развёртки куба.
* **Критическое мышление (`critical`):** факт или мнение, поиск манипуляции в тексте, обманчивые графики, проверка источников.
* **Кругозор (`world`):** география (привязка к стране дня), лента времени (*frise chronologique*), наука, изобретения.

### Типы взаимодействия (`type`):
* `number` — ввод числа (приоритетный формат, исключает угадывание).
* `choice` — выбор из 4 вариантов.
* `boolean_explain` — верно/неверно с выбором обоснования.
* `order` — расстановка 4 карточек в правильном порядке (кнопки вверх/вниз).
* `highlight` — клик по конкретному предложению/фразе в тексте, содержащей ошибку или манипуляцию.

### Схема JSON одной задачи:
```json
{
  "id": "math-0142",
  "category": "math",
  "topic": "divisibility",
  "difficulty": 4,
  "type": "number",
  "lang": "fr",
  "prompt": "Quel est le plus petit nombre divisible à la fois par 4 et par 6 ?",
  "options": null,
  "answer": 12,
  "explanation": "24 marche, mais 12 aussi : 12 = 4×3 = 6×2. C'est le PPCM de 4 et 6.",
  "tags": ["Kangourou"],
  "skill": "multiples",
  "stars": 0,
  "ladder": ["math-0098", "math-0101"],
  "hints": [
    "Pense aux multiples de chacun des deux nombres.",
    "Écris la liste des premiers multiples de 6.",
    "6, 12, 18… lequel est aussi dans la table de 4 ?"
  ],
  "image": null
}
```

## 6. Технический стек, защита данных и Режим родителя
* **Стек:** Vite + React + TypeScript + Tailwind CSS, `vite-plugin-pwa` (полный офлайн), SVG/Canvas для базы и графики, Web Audio API (8-bit звуки без внешних mp3-файлов).
* **Локализация:** все строки интерфейса вынесены в `/src/i18n/fr.json` (с заделом под `ru.json` и `en.json`).
* **Защита от очистки кэша iOS:** так как Safari может очистить `localStorage` после 7 дней неактивности PWA, каждые 5 экспедиций игра предлагает кнопку *«Sauvegarder ma base (+1 Boussole)»*, вызывающую нативное меню «Поделиться» (`navigator.share`) с файлом сохранения `.json`.
* **Режим родителя (вход по 4-значному PIN-коду):**
  * Статистика по категориям за неделю/месяц.
  * Список задач с ошибками (метка «Обсудить вместе»).
  * Ручное управление сложностью / режимом разогрева.
  * Настройка «реальных» наград за тиры сезона (например, Тир 30 = поход в скейт-парк).
  * Загрузка новых пачек задач через `.json` файл + **кнопка «Сформировать промпт для Claude»** (автоматически собирает текст запроса на генерацию новых задач на основе слабых тем игрока).

## 7. Поэтапный план разработки (Roadmap)
* **Этап 1 (MVP — выходные):** Игровой цикл (7 задач), все 5 категорий и типы ответов, черновик-канвас, XP, уровни, комбо-скейт, компасы-подсказки, звёздные задачи, белые пятна, мягкий старт, заглушка базы с запертой «Мастерской ???», упрощённая карта мира, базовый режим родителя, i18n (`fr.json`), сохранение и экспорт JSON, PWA.
* **Этап 2 (Мир — через 1–2 недели):** Полноценная стройка на сетке 12×12, открытие комнат Мастерской (пиксельный редактор 16×16, дизайн деки скейта, свой блок), полная карта мира с дневником капитана и спрятанными сундуками, Зал славы.
* **Этап 3 (Сезоны и контент):** Сезонный пропуск (30 тиров), еженедельные челленджи, расширение банка задач, опциональный ИИ-наставник через защищённую серверную функцию.
